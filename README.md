# Tủ sách của tôi

Ứng dụng Flutter quản lý thư viện sách cá nhân với giao diện Material 3. Người dùng có thể xem thống kê, thêm sách, cập nhật trạng thái đã đọc và xóa sách. Dữ liệu được lưu trong bộ nhớ và sẽ được khởi tạo lại khi ứng dụng khởi động lại.

## Đăng nhập mẫu

- Tên đăng nhập: `admin`
- Mật khẩu: `123456`

## Chạy ứng dụng

```bash
flutter pub get
flutter run
```

## Kiểm tra

```bash
flutter test
flutter analyze
```
